# About PluginUpdateWatch

PluginUpdateWatch is a Paper server administration plugin for discovering plugin update sources, checking for newer releases and downloading updates on request.

## Project

Repository:

[github.com/dylantanderson92-lang/PluginUpdateWatch](https://github.com/dylantanderson92-lang/PluginUpdateWatch)

## Building from source

Requirements:

- JDK 21+
- Maven 3.9+

Build with:

```text
mvn clean verify
```

The installable local artifact is:

```text
target/PluginUpdateWatch-1.3.3-SNAPSHOT.jar
```

Do not install the `original-` JAR.
